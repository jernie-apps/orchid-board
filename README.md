# Orchid Board

Self-hosted task board over GitHub issues (Phase → Feature → Task) plus an MCP server for T3 agents.
Runs on one Mac at `https://orchid.jernie.app` (home network only).

GitHub is the source of truth. The local SQLite DB holds a cache, agent claims and proposals only.

See `AGENTS.md` for build rules and `docs/` for runbooks (added as features land).
